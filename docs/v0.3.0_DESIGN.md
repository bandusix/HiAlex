# HiAlex v0.3.0 设计文档

## 核心理念转变

### 从"安装程序"到"独立应用"

**之前的问题**:
- HiAlex 是一个"安装程序"
- 安装 Paseo CLI
- 安装 Claude CLI  
- 安装桌面应用
- 配置集成
- **太复杂！**

**新的解决方案**:
- HiAlex **就是**应用本身
- 内置 Paseo 功能
- 内置 Claude CLI
- 无需安装任何东西
- **便携式应用**

---

## 新的用户流程

### 简化到极致

```
下载 HiAlex
    ↓
解压/打开
    ↓
首次运行：配置 API Key
    ↓
开始使用！
```

**仅需 3 步！**

---

## 技术架构变化

### v0.2.0（旧）架构

```
HiAlex Installer
    ↓ 安装
Paseo CLI (npm install -g)
    ↓ 安装  
Claude CLI (npm install -g)
    ↓ 配置
Paseo Desktop App
    ↓ 启动
用户使用
```

### v0.3.0（新）架构

```
HiAlex.exe / HiAlex.app
    ├── Paseo (内置)
    ├── Claude CLI (内置)
    └── 配置向导
        ↓
    用户使用
```

## 目标用户体验

### 下载后

1. **Windows**: 
   - 下载 `HiAlex-0.3.0-Portable.exe`
   - 双击运行
   - 配置 API key
   - 立即使用

2. **macOS**:
   - 下载 `HiAlex-0.3.0.dmg`
   - 拖到 Applications
   - 首次运行配置 API
   - 立即使用

### 无需：
- ❌ 安装 Node.js
- ❌ 安装 npm
- ❌ 运行命令行
- ❌ 配置 PATH
- ❌ 理解技术细节

## 配置存储

### 便携式配置
- 配置文件在应用目录下
- `HiAlex/config/settings.json`
- 包含 API key 和用户偏好
- 可以备份整个文件夹

---

## 与 Paseo 的关系

HiAlex 本质上是：
- **Paseo 的桌面版**
- 预装 Claude CLI provider
- 简化的用户界面
- 开箱即用的体验

就像：
- VS Code 是 Electron + Monaco Editor
- HiAlex 是 Electron + Paseo + Claude CLI
